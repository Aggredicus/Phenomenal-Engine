# Independent ReviewForge review instructions

Functionality: replay determinism, RNG ranges and cached-normal persistence,
save and restore equivalence, event ledger integrity, consent, idempotency,
backward compatibility, and cross-module consequences.
Security: untrusted game data, credentials, API paths, decompression, unsafe
deserialization, CI token scope, public saves and authority separation.
Treat a finding as actionable only with a concrete trigger, severity, exact
file/line and disposition. Separate existing risks from introduced regressions.
Normally no more than three review/fix iterations. No auto-approval or release.
